قصة وعبرة — نسخة موصولة بمحرك توليد فيديو (Google Veo 3.1)
============================================================

مهم: هذه نسخة مهيأة للنشر على Render أو للتشغيل محليًا. يلزم مفتاح API صالح من Google AI Studio لتوليد الفيديو.
تحتاج إلى مفتاح API صالح من Google AI Studio، وقد يتطلب التوليد تفعيل الفوترة/توافر النموذج في حسابك ومنطقتك. التوليد قد يستهلك رصيدًا أو يكلّف مالًا.

التشغيل على كمبيوتر Windows:
1) ثبّت Python 3.10 أو أحدث من الموقع الرسمي: https://www.python.org/downloads/
2) افتح مجلد qissa_ai بعد فك الضغط.
3) أنشئ مفتاح API من Google AI Studio: https://aistudio.google.com/apikey
4) افتح Command Prompt داخل المجلد، واكتب:
   set GEMINI_API_KEY=ضع_مفتاحك_هنا
   python server.py
5) افتح في المتصفح: http://127.0.0.1:8000
6) اكتب وصف الفيديو، ثم اضغط «ولّد فيديو واقعي بالذكاء الاصطناعي» وانتظر اكتمال التوليد.

على macOS/Linux:
   export GEMINI_API_KEY='ضع_مفتاحك_هنا'
   python3 server.py
ثم افتح http://127.0.0.1:8000

الأمان:
- لا تضع مفتاح API في صفحة HTML ولا ترسله لأي شخص.
- المفتاح يقرأه الخادم من متغير البيئة فقط.
- الخادم يستمع إلى جهازك المحلي 127.0.0.1 فقط، وليس متاحًا للعامة.
- لا ترفع هذه النسخة كما هي إلى موقع عام. للنشر تحتاج استضافة backend آمنة، متغيرات بيئة سرية، تحديد استخدام ومصادقة، حتى لا يستخدم الآخرون مفتاحك أو رصيدك.

حدود النموذج:
- Veo 3.1 ينشئ مقطعًا واحدًا قصيرًا بطول 8 ثوانٍ في هذا الإصدار.
- اختيار مدة أطول في واجهة القصة لا يجعل هذا الاتصال ينشئ تلقائيًا فيديو طويلًا؛ تجميع عدة مشاهد إلى فيديو 20 دقيقة يحتاج نظام مشاهد/مونتاج منفصلًا.
- الصوت قد يُولَّد ضمن المقطع بواسطة النموذج. النصوص العربية داخل الفيديو قد لا تظهر بدقة؛ الأفضل إضافة الترجمة بعد التوليد في محرر فيديو.
- قد تختلف الإتاحة والأسعار وحدود الاستخدام حسب حساب Google والمنطقة. راجع وثائق Google الرسمية:
  https://ai.google.dev/gemini-api/docs/veo


إعداد Render:
- Root Directory: qissa_ai
- Build Command: pip install -r requirements.txt
- Start Command: python server.py
- أضف Environment Variable باسم GEMINI_API_KEY وضع فيه مفتاح Google AI Studio. لا تشارك المفتاح مع أحد.
